- [cars-backend](https://github.com/WELKAN01/cars-backend): experimento de backend orientado a microservicios para la gestión de autos.
- [front-gestion-productos](https://github.com/WELKAN01/front-gestion-productos): interfaz para la gestión de productos.
- [Products-launcher](https://github.com/WELKAN01/Products-launcher): proyecto relacionado con el lanzamiento y gestión de productos.
